# KisanSetu 🌾

**Farm to Consumer Digital Marketplace** - SIH 2026 Problem Statement SIH26033

## Features
- Direct farmer-to-consumer marketplace
- AI-powered demand forecasting
- Smart logistics & route optimization
- Real-time chat between buyers and sellers
- Role-based access (Farmer, Consumer, FPO, Bulk Buyer)
- Premium UI with Tailwind CSS

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, Chart.js, Framer Motion
- **Backend:** Node.js, Express.js, Socket.io
- **Database:** MongoDB Atlas
- **Auth:** JWT (JSON Web Tokens)

## Deployment
- **Frontend:** Vercel
- **Backend:** Render
- **Database:** MongoDB Atlas

## Environment Variables
```
MONGODB_URI=your_mongodb_atlas_uri
JWT_SECRET=your_secret_key
PORT=5000
CLIENT_URL=https://your-app.vercel.app
```
