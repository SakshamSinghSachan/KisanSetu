1. EXECUTIVE SUMMARY
================================================================================

KisanSetu is a digital marketplace that connects farmers directly with consumers,
eliminating middlemen and ensuring fair prices for both parties. The platform
leverages AI-powered analytics for demand forecasting and smart logistics for
route optimization.

Key Highlights:
- Direct farmer-to-consumer connection
- AI-powered demand forecasting
- Smart logistics with route optimization
- Real-time chat between buyers and sellers
- Role-based access (Farmer, Consumer, FPO, Bulk Buyer)

================================================================================

2. PROBLEM STATEMENT (SIH26033)
================================================================================

Organization: Ministry of Consumer Affairs, Food & Public Distribution
Category: Software
Theme: Agriculture, FoodTech & Rural Development

Problem:
Multiple intermediaries reduce farmers' earnings and increase consumer prices.

Expected Solution:
Create a digital marketplace that:
- Connects farmers/FPOs directly with consumers and bulk buyers
- Provides logistics support
- Uses AI for demand forecasting and route optimization

Benefits:
- Better prices for farmers
- Lower prices for consumers
- Reduced supply chain inefficiencies

================================================================================

3. PROPOSED SOLUTION
================================================================================

KisanSetu addresses the problem by creating a complete digital ecosystem:

a) Direct Marketplace
   - Farmers list products with photos, prices, and descriptions
   - Consumers browse and purchase directly
   - No middlemen involved

b) AI-Powered Analytics
   - Demand forecasting based on historical data
   - Price trend analysis
   - Seasonal demand predictions

c) Smart Logistics
   - Route optimization using Nearest Neighbor algorithm
   - Distance and time calculations
   - Cost estimation for deliveries

d) Communication Platform
   - Real-time chat between buyers and sellers
   - Order status notifications
   - Direct farmer contact

9. KEY ALGORITHMS
================================================================================

9.1 ROUTE OPTIMIZATION (NEAREST NEIGHBOR TSP)
----------------------------------------------

Purpose: Find the shortest path to deliver to multiple destinations

Algorithm Steps:
1. Start at the origin point (farmer's location)
2. Find the nearest unvisited destination
3. Move to that destination
4. Mark it as visited
5. Repeat steps 2-4 until all destinations are visited
6. Calculate total distance using Haversine formula

Time Complexity: O(n^2)
Space Complexity: O(n)

Haversine Formula (Distance between two points on Earth):
d = 2R x arcsin(sqrt(sin^2(dlat/2) + cos(lat1) x cos(lat2) x sin^2(dlng/2)))

Where:
- R = Earth's radius (6371 km)
- dlat = lat2 - lat1
- dlng = lng2 - lng1


9.2 DEMAND FORECASTING
-----------------------

Purpose: Predict future demand based on historical data

Process:
1. Aggregate orders by product category over time
2. Calculate moving averages to identify trends
3. Apply seasonal decomposition
4. Generate confidence intervals
5. Suggest optimal pricing based on demand

Statistical Methods Used:
- Time series analysis
- Moving average
- Trend calculation
- Seasonal indexing

10. SECURITY IMPLEMENTATION
================================================================================

+------------------------------------------------------------------+
|                     SECURITY LAYERS                               |
+------------------------------------------------------------------+

1. PASSWORD SECURITY
   - bcrypt hashing with 12 rounds
   - Salt generation for each password
   - One-way hash (cannot be reversed)

2. AUTHENTICATION
   - JWT (JSON Web Tokens) for stateless auth
   - 30-day token expiry
   - Token stored in localStorage

3. API PROTECTION
   - Middleware verifies token on every protected request
   - Returns 401 if token is invalid/expired

4. ROLE-BASED ACCESS CONTROL
   - Farmer: Can list products, view orders
   - Consumer: Can browse, buy, chat
   - FPO: Bulk management
   - Bulk Buyer: Wholesale purchasing

5. CORS (Cross-Origin Resource Sharing)
   - Restricts API access to frontend URL only
   - Prevents unauthorized domains

6. INPUT VALIDATION
   - Server-side validation on all inputs
   - Sanitization of user data
   - Type checking for all parameters

7. DATA PROTECTION
   - Passwords never returned in API responses
   - Sensitive fields excluded from queries
   - HTTPS encryption in production
